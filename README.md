# Fink_IUCAA2026
Tutorial on how to use Fink tools


Material used to present Fink tools during the [Rubin-LSST Alert Brokers: alerts to discoveries Workshop](https://web.iucaa.in/ws/~lsst-da/), which took place at IUCAA, Pune - India, from 2 - 5 November 2026.

Entry point for all Fink tools is: [https://fink-broker.org/](https://fink-broker.org/)

Additional tutorials can be found at [https://github.com/astrolabsoftware/fink-tutorials](https://github.com/astrolabsoftware/fink-tutorials)
